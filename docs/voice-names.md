## Scope & derivation

- **German given names (~18-65 years old in 2026, i.e. born ~1961-2008):**
  compiled from aggregated German name-frequency-by-decade overviews —
  [familie.de: häufigste Jungennamen/Mädchennamen 1960er-2000er](https://www.familie.de/schwangerschaft/geboren-in-den-60er-jahren-diese-20-maedchennamen-waren-in-der-brd-am-beliebtesten--01HAYWPR24AFSV53QZXKT45TSC),
  [berliner-kurier.de: typische Vornamen Boomer/Millennials/Gen Z (Namensforscher Knud Bielefeld)](https://www.berliner-kurier.de/article/typische-vornamen-boomer-millennials-gen-z-10568069),
  plus well-known evergreen German names not tied to one decade.
  There is no official German name-frequency statistic (no Standesamt-wide public dataset),
  so this is a best-effort aggregate, not an authoritative ranking.
- **English (UK/US) given names:** long-established common first names across the same
  age range (US Social Security Administration / UK ONS top-name territory for the
  relevant decades) — general knowledge, since no single historical top-30-by-decade
  dataset for both countries combined was available; the app is used internationally
  so both German and English coverage matter.
- **Nicknames/short forms:** added as their OWN entries (not aliases) because a nickname
  is a different spoken word from the full name ("Mike" vs "Michael").
- **Not exhaustive by design:** any name missing here is generated once on first use and
  cached centrally by normalized name (see functions/voiceName.js) — see also js/names.js.
